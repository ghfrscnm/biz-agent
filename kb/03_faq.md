# Что взять на первую тренировку
Спортивную форму (футболка, шорты или штаны), воду, полотенце. Тренируемся босиком. Бинты и перчатки на первые занятия даём в клубе бесплатно.

# Экипировка
Со временем понадобятся свои перчатки (10–12 oz для взрослых), бинты, капа и защита голени. Всё можно купить на ресепшене или заказать — тренер подскажет размер.

# Можно ли с нуля
Да, большинство приходит без опыта. Для этого есть группа «Новички»: техника, физподготовка, без спаррингов первые 2 месяца.

# Спарринги и безопасность
Спарринги — только в группе «Взрослые (опытные)» и только в защите. Новички в спаррингах не участвуют. Контроль контакта — тренер.

# Возраст
Дети с 7 лет. Верхнего возраста нет — у нас занимаются и в 50+.

# Справка от врача
Для обычных тренировок не нужна. Для участия в соревнованиях — нужна медицинская справка. При травмах и хронических болезнях советуем сначала проконсультироваться с врачом.

# Женская группа
Отдельная женская группа с тренером Мариной Ветровой: техника, кардио, самооборона, без жёсткого контакта.

# Соревнования
Желающих готовим к городским и областным турнирам по кикбоксингу. Решение принимает тренер по уровню подготовки.

# Родители на тренировке
Родители могут смотреть первую пробную тренировку ребёнка. Дальше — по согласованию с тренером.
